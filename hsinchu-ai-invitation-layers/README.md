# 新竹縣政府 AI 算力合作記者會邀請函：分層素材（300 dpi）

這份邀請函海報已拆成 22 個透明背景圖層，提供 Photoshop 用的 PSD 和逐層 PNG。

![合成預覽](預覽_合成.jpg)

## 規格

| 項目 | 內容 |
|---|---|
| 尺寸 | 4096 × 6144 px |
| 解析度 | 300 dpi（PSD 與 PNG 都已寫入） |
| 輸出尺寸 | 34.68 × 52.02 cm（約 13.65 × 20.48 in） |
| 色彩 | RGB 8-bit (sRGB) |
| 來源 | 原圖 1024 × 1536 px，用 AI 超解析度（EDSR ×4）放大後再分層 |

## 檔案

| 檔案 | 用途 |
|---|---|
| `新竹縣政府AI記者會邀請函_分層_300dpi.psd` | 分層 PSD，有 4 個群組和 22 個圖層，可以直接在 Photoshop 打開調整 |
| `PNG分層/00_…png` ~ `21_…png` | 逐層透明 PNG。每張都是完整畫布大小，按編號由下往上疊就能對齊還原 |
| `背景_去字完整版_300dpi.png` | 去掉所有文字、保留全部圖形的完整背景，可以直接拿來重新排字 |
| `預覽_合成.jpg` | 所有圖層合成後的預覽（1/4 尺寸） |
| `圖層總覽.jpg` | 每個圖層的縮圖總覽 |
| `scripts/` | 製作流程用的 Python 腳本。要重跑時，先把原圖存成 `scripts/poster_src.png`，再依序執行 `sr_full.py`（需要 EDSR_x4.pb 模型）→ `stage2.py` → `export.py` |

## 使用注意

- **文字是點陣圖層，不是可編輯文字。** 大標題放大後邊緣仍然清楚。說明文字、日期這類小字在原圖只有約 28 px 高，放大 4 倍後會稍微柔一點。正式大尺寸印刷時，建議在 Photoshop 用相近字體重新打字，例如思源宋體／Noto Serif TC 的 Bold 或 Black。
- **被遮住的區域是平滑補色。** 背景底圖裡，原本被地球和資訊框蓋住的區域，以及地球圖層裡 4 個圖示底下的位置，原圖都沒有內容，這裡用周圍顏色平滑補上。保持原位置時看不到；把地球、圖示或資訊框移開，會露出一塊模糊色塊。
- 去字時，順便清掉了文字邊緣的 WebP 壓縮雜點。所以合成結果比原圖乾淨一點，但版面完全一致。
- 印刷尺寸不同（例如 A2）時，直接在 Photoshop 用「影像尺寸」調整即可，解析度維持 300 dpi。
